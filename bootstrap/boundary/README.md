# Boundary

GitHub shows this file for the folder. FON is the wire. It is not a compiler stage. The OKF index is [index.md](index.md).

- [source](01-source.md) turns raw bytes into FON.
- [fon](02-fon.md) is the inert codec.
- [pipe](03-pipe.md) is `defonify`, then the stage, then `fonify`.
- [render](04-render.md) turns the last FON value back into text.
