# Compositions

GitHub shows this file for the folder. A composition is a program that orders passes. It is not the semantics. The OKF index is [index.md](index.md).

- [Pass](pass.md) is the `>>` object.
- [Run](run.md) is the chain the walker actually runs.
- [Build](build.md) and [inspect](inspect.md) are the longer chains, as signatures.
