# Boundary

GitHub shows this file for the folder. FON is the wire. It is not a compiler stage. The OKF index is [index.md](index.md).

- [source](source.md) turns raw bytes into FON.
- [fon](fon.md) is the inert codec.
- [pipe](pipe.md) is `defonify`, then the stage, then `fonify`.
- [render](render.md) turns the last FON value back into text.
